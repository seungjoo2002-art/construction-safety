# 건설사고 위험 예측 모형 — 배포 패키지 (31피처, 연령 포함)

앱 연동용 학습 완료 모형과 추론 모듈입니다. 이전 패키지(30피처)를 대체합니다.

> **이전 패키지 대비 변경점**
> 1. 입력에 **작업자 연령**이 추가되었습니다 (30 → 31피처).
> 2. 학습 데이터가 **피해자 단위**로 바뀌었습니다 ("이 작업자가 사고를 당한다면"을 예측).
> 3. XGBoost(심각도 · 사고유형 base)가 범주형 값을 순번으로 읽는 문제를 고쳤습니다.
>    **이전 패키지의 `predict.py`는 한 건씩 예측하면 XGBoost가 범주를 잘못 읽었습니다.** 이 패키지로 교체해 주세요.

## 0. 이 모형이 답하는 것 / 답하지 않는 것

> **답하지 않음**: "오늘 사고가 날 확률"
> **답함**: "이 조건에서 이 작업자가 사고를 당한다면, 얼마나 심각하고 어떤 유형일 것인가"

학습 데이터가 **사고 발생 사례만**으로 구성되어 있어 발생 빈도는 예측할 수 없습니다.
UI 문구를 `"사고 위험 23%"`로 쓰면 안 되고, `"사고 발생 시 치명 위험 — 상위 8%"` 형태로 표기해야 합니다.

반환값 (`python predict.py`의 실제 출력):

  "injury_type": {"끼임": 0.3586, "절단·베임·찔림": 0.0683, "추락·압착": 0.2071,

## 3. 입력 변수 31개

`artifacts/feature_spec.json`의 `input_tiers`에 계층별로 정리돼 있습니다.
누락된 키는 자동으로 결측 처리되지만, **매일 입력 3개 · 연령 · 근무형태는 반드시 채워야** 예측이 의미 있습니다.

### 3-1. 매일 입력 (3개) — 사용자 드롭다운

| 키 | 선택지 |
|---|---|
| `사고객체_대분류` | `allowed_values.사고객체_대분류` (가시설, 건설공구, 건설기계, 건설자재, 기타, 부재, 시설물, 질병, 토사 및 암반) |
| `작업프로세스` | `allowed_values.작업프로세스_clean` 중 하나. 목록에 없는 값은 내부에서 `기타`로 치환 |
| `추출된_작업종류` | `allowed_values.추출된_작업종류` (10종) |

`사고객체_대분류`는 **오늘 작업에서 사용·취급하는 객체**를 묻습니다. 권장 질문:
- 오늘 사용할 공구가 있나? (그라인더, 원형톱, 사다리 등) → `건설공구`
- 비계 · 작업발판 · 거푸집 위에서 작업하나? → `가시설`
- 자재를 운반하거나 가공하나? → `건설자재`
- 주변에서 중장비가 운용되나? → `건설기계`
- 해당 없음 → `기타`

여러 개에 해당하면 객체마다 `predict`를 호출하고 **가장 높은 위험**을 보여주는 것을 권장합니다.

### 3-2. 작업자 정보 (1개) — 신규

아래 셋 중 하나로 넣으면 됩니다. 모형 내부에서는 `연령_ord`(0~5)로 변환됩니다.

| 키 | 예 | 비고 |
|---|---|---|
| `연령_ord` | `4` | 0=10대, 1=20대, 2=30대, 3=40대, 4=50대, 5=60대 이상 |
| `연령대` | `"50대"` | `10대` / `20대` / `30대` / `40대` / `50대` / `60대 이상` |
| `나이` | `54` | 만 나이 → 연령대로 자동 변환 |

### 3-3. 근무형태 (1개) — 근무 계획에서 자동 도출

`정규작업` / `휴일근무` / `연장근무` 중 하나. 판별 불가 시 `UNKNOWN`.

```python
if 공휴일 or 주말근무:      근무형태 = "휴일근무"
elif 정규종업시각 초과:      근무형태 = "연장근무"
else:                       근무형태 = "정규작업"
```

### 3-4. 현장 등록 시 1회 (10개)

`공종 - 중분류`, `공공/민간 구분`, `시설물 종류 - 대분류`, `시설물_중분류`,
`안전관리계획`, `설계안전성검토`, `공사비_ord`, `작업자수_ord`, `낙찰률_ord`, `전체공사일수`

- 범주형 값은 `category_mapping`에 있는 문자열을 그대로 쓰세요. 예: `안전관리계획` = `대상현장(1/2종)` / `대상현장(1/2종외)` / `비대상현장`
- `공공/민간 구분`은 `"공공"` / `"민간"` (또는 0 / 1)
- 순서형(`_ord`) 구간 정의는 `_common_add_3class.py`의 `COST_MAP`(17단계) / `WORKER_MAP`(6단계) / `BID_MAP`(8단계)

### 3-5. 자동 수집 (16개)

| 키 | 설명 |
|---|---|
| `기상상태 - 습도`, `평균기온(°C)`, `일강수량(mm)`, `평균 풍속(m/s)` | 당일 관측/예보 |
| `기온_D1~D3`, `강수_D1~D3`, `풍속_D1~D3` | 1~3일 전 값 (지연항) |
| `사고_월`, `사고_요일`, `사고_시간` | 조회 시점. 요일은 월=0 ~ 일=6 |

## 4. 상대 위험도 계산

절대 확률 대신 **백분위**를 씁니다. 모형은 RUS와 class weight로 학습해 출력 확률이 실제 발생률과 어긋나 있습니다
(실제 치명률 5.8%인데 모형 평균은 20%대). `P(치명)=0.23`을 그대로 띄우면 틀린 정보입니다.

```
상대위험도(%) = searchsorted(REF, P_치명) / len(REF) × 100
```

`REF`(`artifacts/ref_distribution.npy`, 27,907개)는 전체 데이터를 **5-fold OOF**(사고 단위 그룹)로 예측한 P(치명)을 정렬한 배열입니다.
배포 모형과 같은 인코딩으로 계산했습니다.

| 등급 | 백분위 |
|---|---|
| 낮음 | 0 ~ 50 |
| 보통 | 50 ~ 75 |
| 높음 | 75 ~ 90 |
| 매우 높음 | 90 ~ 100 |

구간을 조정하려면 `metadata.json`의 `relative_risk.grades`를 수정하세요.

## 5. 모형 구조

### 심각도 3분류 — 경+중등도 / 중상 / 치명

```
RandomUnderSampler(다수:치명 = 3:1)
  → XGBoost + LightGBM + CatBoost 각각 학습
  → predict_proba 단순평균 (소프트보팅)
```

### 사고유형 5분류 — 끼임 / 절단·베임·찔림 / 추락·압착 / 물체에 맞음 / 전도·충돌

```
base 3종(XGB·LGBM·CatBoost)을 3-fold로 학습 (사고 단위 그룹)
  → 각 fold 모형의 예측확률 평균 (fold당 1/3)
  → 3종 × 5클래스 = 15차원 메타피처
  → 메타러너 XGBoost (Stacking-XGB)
```

base 모형이 fold별로 3개씩(총 9개) 저장돼 있습니다. `predict.py`가 fold 평균을 처리합니다.

### 학습 데이터

- 원본 CSI 32,288건(사고 단위)을 연령대별 사망자 · 부상자 수로 **피해자 단위**로 재구성
- 심각도 27,907명 / 사고유형 29,117명
- 사망 · 부상 혼재 사고의 부상자(150명)는 부상 정도를 알 수 없어 심각도 학습에서 제외
- 연령 정보가 없는 사고(13%)는 관측 연령 분포로 대체

## 8. 연동 시 주의사항

1. **`RiskPredictor()`는 프로세스당 1회만 생성**하세요. 모형 13개를 로드하므로 요청마다 만들면 느립니다.
2. **범주형 값은 문자열이 정확히 일치해야 합니다.** `category_mapping`에 없는 값은 `-1`(결측)로 처리됩니다. 드롭다운을 `allowed_values`에서 생성하는 것을 권장합니다.
3. **범주 순번을 직접 다루지 마세요.** 범주는 `category_mapping`의 순번(0..K-1)으로 고정해 category로 바꿔야 합니다. 행마다 따로 category로 바꾸면 XGBoost가 순번을 다르게 읽어 예측이 틀어집니다. `predict.py`가 처리하므로 직접 모형을 호출할 때만 주의하세요.
4. **피처 순서를 바꾸지 마세요.** `feature_order`를 그대로 따라야 합니다.
5. **`사고_요일`은 월=0 ~ 일=6** (pandas `dayofweek` 기준).
6. 결과를 로그로 남길 때 입력 payload도 함께 저장해두면 이후 재학습에 쓸 수 있습니다.
